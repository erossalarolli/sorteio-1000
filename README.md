# Sorteio 1000

Sistema de reserva de números 0001 a 1000.

## Estrutura obrigatória
app.py
requirements.txt
render.yaml
README.md
templates/
  index.html
  admin.html
  admin_login.html
static/
  style.css

## Recursos
- Um número só pode ser reservado uma vez.
- Um WhatsApp/telefone só pode reservar um número.
- Registro com data e hora.
- Painel administrativo.
- PostgreSQL.
- Horário exibido em America/Cuiaba.
